Architecture

How DeepScan Works

A four-layer detection pipeline combining spatial facial geometry with RNN temporal analysis and persistent vector storage.

01

Media Ingestion

Uploads decoded frame-by-frame. Face regions extracted via MTCNN and normalized to 224×224 tensors.

02

Landmark Analysis

468 3D facial keypoints mapped per frame. Geometric ratios and structural anomalies computed per region.

03

RNN Temporal Scan

Bi-directional LSTM processes 32-frame sequences to detect unnatural motion and GAN warping artifacts.

04

Vector Storage

128D face embeddings stored in MongoDB Atlas with cosine-similarity index for audit trails.

Backend Architecture

MongoDB Vector Storage

Every analyzed face generates a 128-dimensional embedding stored in Atlas with a cosine-similarity index for fast retrieval and GAN family detection.

🗄️

Document Schema

Each analysis stored as a rich document including the full 128D face vector, landmark data, RNN sequence features, and metadata.

"_id": ObjectId("..."), "file_hash": "sha256:3f8a...", "verdict": "FAKE", "confidence": 0.932, "embedding": [0.23, -0.71, ...], // 128D "landmarks": { /* 468 points */ }, "rnn_seq": [...], // 32 frames "timestamp": ISODate("2026-04-25"), "model_ver": "bilstm-v2.4"

Vector Search Index

RNN Architecture

Bi-directional LSTM with 3 layers processes 32-frame sequences. Trained on FaceForensics++, DFDC, and CelebDF-v2 datasets.
